# Lillian's Stories

A series of books telling the story of **Lillian**, a woman from the late Generation X, born in 1979 in Heidelberg, whose very rich life can be organized into a collection of books. The project is currently in its information-gathering phase: no book is written yet, and the material is built little by little as Markdown files.

## Contents

| Name | Description |
|---|---|
| [Eras](eras/README.md) | The 7 large parts of Lillian's life, each a candidate for a book in the collection. |
| [Periods](periods/README.md) | The 14 periods that make up the eras, the chapters of each book. |
| [People](people/README.md) | The 17 people who are part of Lillian's life, Lillian herself being the main character. |
